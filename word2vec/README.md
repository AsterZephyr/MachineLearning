# Word2Vec词向量模型Demo

## 简介
Word2Vec是Google开发的一种用于生成词向量的神经网络模型，能够将词语映射到高维向量空间，使语义相似的词在向量空间中距离更近。

## 主要功能
1. **词向量训练** - 从文本语料训练词向量模型
2. **词相似度计算** - 计算两个词之间的相似度
3. **相似词查找** - 找到与给定词最相似的词
4. **词向量运算** - 支持词向量的加减运算和类比推理
5. **模型保存加载** - 保存训练好的模型供后续使用
6. **可视化** - 将高维词向量降维可视化

## 安装依赖
```bash
pip install -r requirements.txt
```

## 运行Demo
```bash
python word2vec_demo.py
```

## Demo功能演示
- 准备中文训练语料并分词
- 训练Word2Vec模型（Skip-gram）
- 词相似度计算
- 相似词查找
- 词向量运算和类比推理
- 词向量可视化（PCA降维）
- 模型保存和加载
- 模型评估

## 输出文件
- `word2vec_model.model` - 完整的Word2Vec模型
- `word_vectors.kv` - 仅词向量文件
- `word_vectors_visualization.png` - 词向量可视化图
