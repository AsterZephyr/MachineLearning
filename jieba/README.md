# jieba分词工具Demo

## 简介
jieba是Python中最流行的中文分词库，支持三种分词模式：精确模式、全模式和搜索引擎模式。

## 主要功能
1. **中文分词** - 将中文文本切分成词语
2. **词性标注** - 标注每个词的词性（名词、动词等）
3. **关键词提取** - 使用TF-IDF和TextRank算法提取关键词
4. **自定义词典** - 添加领域专用词汇
5. **并行分词** - 支持多线程加速分词

## 安装依赖
```bash
pip install -r requirements.txt
```

## 运行Demo
```bash
python jieba_demo.py
```
